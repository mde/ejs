# Contributing to EJS

Bug reports and pull requests are welcome. Run `npx jake test` before
submitting, and add tests for any behavior you change.

Security issues go through [SECURITY.md](SECURITY.md), not public issues.

## AI-generated pull requests

EJS is installed tens of millions of times a week, so every change that lands
is one the maintainer has to stand behind. Pull requests that are obviously
AI-generated (for example, from accounts opening many PRs across unrelated
projects) won't be merged.

If the underlying bug or improvement is real, the maintainer may fix it
independently and close the PR with a link to the fix.

Using AI tools to help with your own work is fine. Tell us you used them,
and be ready to explain and maintain the change yourself.
